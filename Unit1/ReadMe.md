#  Unit 1 – Introduction to Python, Strings & Numbers

Welcome to **Unit 1** of the **FNB App Academy – Introduction to Python** course.

This unit introduces the fundamentals of Python programming, including variables, user input, strings, numbers, and formatted output. The projects in this folder focus on solving simple real-world problems while building confidence with Python syntax.

---

##  Projects

###  TheConcertTicketBooker.py

**Real-world problem**

Concert organisers need a quick way to collect customer details and generate a personalised booking confirmation.

**Solution**

This program asks the user for their personal information, such as their name and ticket details, then displays a formatted booking confirmation using Python variables and string formatting.

**Concepts Practised**

- Variables
- User input (`input()`)
- Strings
- Formatted output (`f-strings`)
- Basic Python syntax

---

###  student_info.py

**Real-world problem**

Educational systems often need to collect and display basic student information in a clear format.

**Solution**

This program collects a student's personal details and displays them back to the user in a readable format. It serves as an introduction to storing data in variables and working with different data types.

**Concepts Practised**

- Variables
- Strings
- Integers
- Floats
- User input
- Type casting
- Formatted output

<summary><strong> Python vs C# Perspective</strong></summary>

As someone who learned **C# before Python**, I naturally found myself comparing concepts between the two languages while completing this unit.

Although Python has a much simpler syntax, I discovered that the underlying programming concepts are the same.

| Concept | Python | C# |
|---------|---------|------|
| Variable | `name = "Hope"` | `string name = "Hope";` |
| User Input | `input()` | `Console.ReadLine()` |
| Output | `print()` | `Console.WriteLine()` |
| String Formatting | `f"{name}"` | `$"{name}"` |
| Comments | `# Comment` | `// Comment` |

One of the biggest lessons I learned was that learning a new programming language is often about learning **new syntax rather than completely new ideas**. Once I started relating Python concepts to C#, the language became much easier to understand.
