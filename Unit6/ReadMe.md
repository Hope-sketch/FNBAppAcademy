#  Projects

##  Directory_search.py

### Real-world Problem

Phone directories and contact applications need an efficient way to search for someone's contact details using their name.

### Solution

This program stores contacts in a Python dictionary and allows the user to search for a person's phone number. If the contact exists, their number is displayed; otherwise, the program informs the user that the contact could not be found.

### Concepts Practised

- Dictionaries
- Dictionary Keys and Values
- `if` Statements
- User Input
- Searching Data

##  grade_report.py

### Real-world Problem

Teachers often need to process an entire class of students rather than calculating grades one learner at a time.

### Solution

This application processes multiple student records, calculates averages, assigns grades, determines pass or fail status, and produces class statistics such as:

- Class Average
- Highest Average
- Lowest Average

The program also allows the user to search for individual students after the report has been generated.

### Concepts Practised

- Lists of Dictionaries
- `for` Loops
- `while` Loops
- Nested Logic
- Searching
- Functions
- Data Processing

#  Python vs C# Perspective

This unit was where everything finally clicked.

At first, I tried approaching Python exactly like C#, which sometimes made simple problems more complicated than they needed to be. As I worked through these exercises, I realised that Python encourages simpler solutions while still using the same programming fundamentals.

| Python | C# |
|---------|------|
| Dictionary | `Dictionary<TKey, TValue>` |
| List of Dictionaries | `List<Dictionary<TKey, TValue>>` or `List<Student>` |
| `for student in students:` | `foreach (var student in students)` |
| `while True:` | `while(true)` |
| `break` | `break` |

The biggest lesson I learned was that learning a new language isn't about forgetting what you already know—it's about expressing familiar ideas using a different syntax.
