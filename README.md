##  About This Repository

Welcome!

This repository contains my completed practical tasks and challenge exercises from the **FNB App Academy – Introduction to Python** course.

The goal of this repository is not only to showcase my work, but also to help beginners understand Python through simple, well-commented examples.

As someone who already had experience with **C#**, I documented many of my thought processes by comparing Python concepts to C#. If you're learning Python after another programming language, you may find these explanations useful.

#  Getting Started

## Step 1 — Install Python

Download Python from:

https://www.python.org/downloads/

✔ Remember to tick **"Add Python to PATH"** during installation.

---

## Step 2 — Install Visual Studio Code

Download Visual Studio Code from:

https://code.visualstudio.com/

---

## Step 3 — Install the Python Extension

Open Visual Studio Code.

Go to:

Extensions → Search **Python**

Install the official extension published by **Microsoft**.

---

## Step 4 — Clone this Repository

```bash
git clone https://github.com/Hope-sketch/FNBAppAcademy.git
```
