#  Projects

##  ATM_withdrawal.py

### Real-world Problem

Banks need to verify whether a customer has sufficient funds before approving a withdrawal. They must also prevent invalid withdrawal requests, such as negative amounts or withdrawing more money than is available.

### Solution

This program simulates a simple ATM by:

- Storing an account balance
- Asking the user how much they would like to withdraw
- Checking whether the withdrawal is valid
- Updating the remaining balance when appropriate

### Concepts Practised

- `if`
- `elif`
- `else`
- Comparison Operators
- User Input
- Variables

##  grade_classifier.py

### Real-world Problem

Schools need a quick and consistent way to calculate student averages, assign grades, and identify learners who may need additional academic support.

### Solution

This application:

- Collects marks for three subjects
- Calculates the average
- Assigns a letter grade
- Determines whether the student passed or failed
- Flags students who may need additional academic intervention

### Concepts Practised

- `if`
- `elif`
- `else`
- Multiple Conditions
- Logical Operators (`and`, `or`)
- Variables
- User Input

#  Python vs C# Perspective

This unit felt almost identical to writing decision-making logic in C#.

| Concept | Python | C# |
|---------|---------|------|
| If Statement | `if` | `if` |
| Else If | `elif` | `else if` |
| Else | `else` | `else` |
| AND | `and` | `&&` |
| OR | `or` | `||` |
| Equal To | `==` | `==` |

The logic never changed—only the syntax did. Once I stopped thinking about Python as a completely different language, these exercises became much easier.
