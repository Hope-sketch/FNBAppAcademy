- Total trip cost
- Displays the result rounded to two decimal places.

#  Python vs C# Perspective

Since I learned **C# before Python**, I naturally compared how both languages perform mathematical operations.

| Concept | Python | C# |
|---------|---------|------|
| Integer | `10` | `int number = 10;` |
| Decimal Number | `10.5` | `double number = 10.5;` |
| Convert to Integer | `int(value)` | `Convert.ToInt32(value)` |
| Convert to Decimal | `float(value)` | `Convert.ToDouble(value)` |
| Round a Number | `round(value, 2)` | `Math.Round(value, 2)` |

One thing that surprised me was how little actually changed. The formulas stayed exactly the same—the only difference was the syntax used to write them.
