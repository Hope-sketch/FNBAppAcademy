#  Python vs C# Perspective

As someone who learned **C# before Python**, this unit felt surprisingly familiar. Both languages provide powerful tools for manipulating strings—the biggest difference is the syntax used to access them.

| Task | Python | C# |
|------|---------|------|
| Convert to Uppercase | `text.upper()` | `text.ToUpper()` |
| Convert to Lowercase | `text.lower()` | `text.ToLower()` |
| Remove Spaces | `text.strip()` | `text.Trim()` |
| Replace Text | `text.replace()` | `text.Replace()` |
| Length | `len(text)` | `text.Length` |

One thing I learned during this unit is that Python's string methods are very readable. While I naturally compared them to their C# equivalents, I realised both languages solve the same problems using slightly different syntax.
